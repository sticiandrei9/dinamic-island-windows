# v0.3.0 Implementation Plan

> Execuție inline (superpowers:executing-plans), TDD pe logica pură, un review final independent.

**Goal:** apeluri (microfon + mute), capturi de ecran în insulă, interfață RO/EN/RU, corecturile rămase; release v0.3.0.
**Spec:** `docs/superpowers/specs/2026-10-15-v030-design.md`

## Global Constraints
- `windows` 0.58; designul insulei (arc 0.5/0.72, negru, urechi) neschimbat; activitățile noi trec prin `island.setActivity` / `pushTransient`.
- Comentarii/commit-uri în română; textele UI doar prin `t()` după Task 1.
- Teste complete (`npm test`, `cargo test`) înainte de fiecare commit.

## Review Focus
1. Limba „auto” pe un Windows în altă limbă decât ro/ru → engleză, fără chei brute afișate.
2. Clipboard cu imagine din alt program (browser, Paint) → nicio miniatură.
3. Mute când nu există microfon / dispozitivul dispare → eroare tratată, fără panică.
4. Două capturi rapide → „Salvează” pe prima dă eroare clară, nu salvează a doua.
5. `media-update` fără `thumbnail` ajuns la o fereastră nouă → coperta corectă, nu placeholder.

## Tasks
1. **i18n:** `src/locales.json`, `src/lib/i18n.js` (+ test chei/parametri/plurale), `src-tauri/src/i18n.rs` (`resolve`, `t`, test), `Settings.language` + `resolved_language` în `get_settings`/`settings-changed`.
2. **Traduceri:** setări (HTML `data-i18n`, `settings.js`, `settings-ui.js` cu plurale), insulă (`index.html`, `island.js`, toate view-urile), tray (+ refresh la schimbarea limbii), notificarea de update, `alerts.rs`.
3. **Apeluri:** `privacy.rs` (`mic_since`, `mic_muted`, `filetime_to_unix_ms`, `earliest_start`), `mic.rs` (`mic_set_mute`), modul `calls`, `calls-view.js`, `PRIORITY.call`, slot `c-call`.
4. **Capturi:** `screenshot.rs` (`dib_to_rgba`, `thumb_size`, `find_recent`, thread clipboard, comenzi), modul `screenshots`, `screenshot-view.js`, `holdHead` în `activities.js`, hover fără extindere pe tranzitorii interactive.
5. **Corecturi Rust/JS** #1–#10, #15–#21, #23, #24 din spec, fiecare cu test unde e logică.
6. **Release script** #11–#14 (+ test pentru `package-lock.json`).
7. **#26** calea de 3 ori la tragerea în terminal: investigare, corectură dacă e de la noi.
8. **README (3 limbi), CLAUDE.md**, build release, verificare pe calculator, review final, fix-uri, `npm run release -- 0.3.0`.
