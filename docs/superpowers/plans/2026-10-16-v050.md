# v0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Șapte module noi în insulă (Claude, descărcări, lacăt, sistem + rețea, clipboard, somn, notițe), livrate împreună ca v0.5.0.

**Architecture:** Fiecare funcție e un modul Rust nou în `src-tauri/src/` (thread propriu, logică pură testată, evenimente spre insule) plus un `src/<nume>-view.js` încărcat dinamic de `island.js`, ca modulele existente. Setările primesc chei noi în `Modules`; cele sensibile (`claude`, `clipboard`) și `notes_hotkey` sunt oprite implicit. Hook-ul Claude rulează exe-ul instalat în mod CLI (`--claude-hook`), care scrie un fișier de stare și iese înainte de Tauri.

**Tech Stack:** Rust (Tauri 2, `windows` 0.58, `serde_json`), JS ES modules fără bundler, `node --test`, `cargo test`.

**Spec:** `docs/superpowers/specs/2026-10-16-v050-design.md`

## Global Constraints

- Regulile din `CLAUDE.md`, secțiunea „Hard-won rules”: fără `ShowWindow` direct pe insulă; fără `WS_EX_TOOLWINDOW` după creare; `windows` rămâne `0.58`; Win32 doar pe thread-ul care deține fereastra/hotkey-ul; după orice modificare în `src/` se recompilează înainte de test.
- `PATH` pentru Rust în Bash: `export PATH="$HOME/.cargo/bin:$PATH"`.
- Text UI doar prin `t()` / `data-i18n`, chei noi în `src/locales.json` în `ro`, `en` **și** `ru`, cu aceiași parametri `{…}` (testul `tests/i18n.test.js` trebuie să treacă).
- Comentarii, commit-uri, docs: în română. Commit-uri cu autorul noreply din config-ul repo-ului și linia `Co-Authored-By` dată de harness.
- Păstrează EOL-ul fiecărui fișier (unele sunt CRLF). Liniile cu `\n`, `\\` din surse Rust/JS se editează cu Edit, nu prin heredoc.
- Modulele noi: `claude`, `downloads`, `unlock`, `system`, `clipboard`, `sleep`, `notes`. Implicit: `claude = false`, `clipboard = false`, celelalte `true`. `notes_hotkey` implicit `""`; sugestia afișată în Setări: `Win+Shift+N`.
- Ping spre `1.1.1.1`, la 5 s, timeout 1 s. Senzorii din fila Sistem se citesc doar cât fila e deschisă (1 s; temperatura GPU vezi Task 6).
- Clipboard: 5 texte, doar în memorie, niciodată în log/disc; tranzitoria „Copiat: <primele ~40 de caractere>” 2 s; textele cu formatele de excludere nu apar nicăieri.
- Timer de somn: 15 / 30 / 60 min; fade liniar al volumului master în ultimele 10 s, apoi pauză, apoi volumul revine.
- Descărcări: fără procent — inel care se rotește + `<MB> · <MB/s>`.
- Iconița Claude e o steluță generică, nu logo-ul Anthropic.
- Niciun `npm run release`, push sau schimbare de vizibilitate fără acordul explicit al lui Andrei.
