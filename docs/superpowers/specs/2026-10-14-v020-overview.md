# v0.2.0 — Prezentare generală

Data: 2026-10-14

Release-ul v0.2.0 adaugă 14 îmbunătățiri (calendarul a fost scos) și un nou mod de actualizare. E împărțit în 4 părți. Fiecare are specificația ei, planul ei și implementare cu teste, iar la final iese un singur release.

| Parte | Specificație | Conține |
|---|---|---|
| D. Aplicația | `2026-10-14-v020-d-app-design.md` | setări, mai multe monitoare, mărime, log, update-uri cu „Aplică” |
| B. Activități | `2026-10-14-v020-b-activities-design.md` | cadrul de activități (pastilă + bulă), file în insula extinsă, timer/cronometru, microfon/cameră, alerte de sistem, volum/luminozitate, notificări Windows |
| A. Media | `2026-10-14-v020-a-media-design.md` | bară de progres trasabilă, click deschide sursa, versuri sincronizate |
| C. Utilitare | `2026-10-14-v020-c-utilities-design.md` | raft de fișiere, oglindă cameră |

**Ordinea de implementare:** D → B → A → C. D aduce setările și log-ul, de care au nevoie toate celelalte. B aduce cadrul de activități și filele insulei extinse, pe care A și C le folosesc.

## Reguli comune tuturor părților

- **Design:** „aproape identic cu MacBook-ul / iPhone-ul”: negru pur, spring cu ușor overshoot, conținut cu blur + fade + scale. Orice element nou respectă `CLAUDE.md` → „The design goal”.
- **Setări:** fiecare funcție nouă are un comutator în Setări → Module. Când e oprită, nu consumă nimic: thread-ul ei nu rulează, iar ascultătorul ei nu e înregistrat.
- **Consum:** CPU în repaus sub 1% dintr-un nucleu cu toate modulele pornite; nicio sondare mai deasă de 500 ms, cu excepția hit-test-ului existent (30 ms).
- **Erori:** un modul care eșuează (un API Windows indisponibil, lipsa rețelei) scrie în log și se dezactivează singur; nu blochează insula și nu o închide.
- **Texte:** toate textele vizibile sunt în română.
- **Teste:** logica pură e extrasă în funcții testate (`src/lib/*.js`, funcții pure în fiecare modul Rust). Pentru UI, verificare vizuală cu capturi de ecran.
- **Release:** abia după ce toate cele 4 părți sunt gata, revizuite și verificate pe calculatorul lui Andrei: `npm run release -- 0.2.0 "…"`, doar cu acordul lui.
